# Contributing to Modern Calculator

Thank you for your interest in contributing to Modern Calculator! 🧮

## Ways to Contribute

### 🐛 Reporting Bugs
1. Check [existing issues](https://github.com/deniscasian699/Modern-Calculator/issues) to avoid duplicates
2. Use the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md)
3. Include:
   - Steps to reproduce
   - Expected vs actual behavior
   - Device info (model, Android version, app version)
   - Screenshots if applicable

### 💡 Suggesting Features
1. Check [existing feature requests](https://github.com/deniscasian699/Modern-Calculator/issues?q=is%3Aissue+label%3Aenhancement)
2. Use the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md)
3. Explain the problem it solves and proposed solution

### 🌍 Translating
1. Report a translation issue with the language, screen and suggested wording.
2. This repository archive contains documentation and promotional assets, not the Android source or translation resources.

### 🛠️ Documentation and asset contributions
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature-name`
3. Update the relevant documentation or asset
4. Check links, spelling and image rendering
5. Commit with clear messages: `git commit -m "Add: feature description"`
6. Push to your fork: `git push origin feature/your-feature-name`
7. Open a pull request

The Android project cannot be built from this documentation-and-assets archive. For app bugs or feature requests, use [bugs.rdcapps.com](https://bugs.rdcapps.com/).
