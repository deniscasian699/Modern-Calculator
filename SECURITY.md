# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | ✅        |

## Reporting a Vulnerability

**Do not report security vulnerabilities through public GitHub issues.**

Report via:
- **Email:** support@rdcapps.com
- **Subject:** `[SECURITY] Modern Calculator - [brief description]`

Response within 48 hours. Confirmed issues will be patched and credited.

## Security Practices

- Local-only calculation processing
- No account system
- Advertising is disabled for Remove Ads owners and active Supporter subscribers; Premium alone remains ad-supported
- Google Play Billing for secure payments
- GDPR/CCPA compliant consent via Google UMP
